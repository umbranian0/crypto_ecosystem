# RAV-011 — Visible link from the runs list to the existing cross-run trend view

**Status: done.**

**Module**: `services/dashboard-web` only.
**Story**: `RAV-011`, `docs/product/backlog-run-analysis-visualization.md` Epic D.
**Depends on**: none (links to `RAV-009`, already shipped Sprint 28).
**Sprint**: 60 (`docs/sprints/sprint-60.md`). Sequenced **first** — smallest, lowest-risk edit to
`runs_list.html`, landing before RAV-012/013/014's heavier edits to the same file.

## Analysis

`services/dashboard-web/src/app/templates/runs_list.html` (46 lines, read in full) has zero chart
markup and no link anywhere to `/runs/trend` (the `runs_trend` route, `src/app/routers/runs.py` line
1058/1059, RAV-009, already shipped). A tenant browsing the plain runs list has no way to discover the
cross-run trend/consistency view without already knowing its URL. This ticket closes exactly that gap —
nothing else.

Constraint from the backlog (binding): link copy must reuse `/runs/trend`'s own existing framing, not
new independently-worded marketing copy. `runs_trend.html` line 6 already reads: *"Select a
dataset/horizon configuration to see how this model configuration's validation results have varied
across its completed runs."* — reuse this framing verbatim or near-verbatim for the link's surrounding
copy.
