# UAT-007 — Type `RunRequest.dataset_reference` in the OpenAPI schema

**Module**: `libs/common` (`naive_first_common.contracts.RunRequest`), mirrored in
`services/gateway-api`'s local `RunRequest` copy. **Depends on**: none. **Blocks**: UAT-008 (Track C),
file-ordering only — UAT-008 must not edit `RunRequest` concurrently with this ticket.

## Analysis
Story: `docs/product/backlog-uat-findings.md` UAT-007. `RunRequest.dataset_reference: dict` renders as
bare `additionalProperties: true` in `GET /openapi.json`. Real shape (per
`InlineOrLocalFileDatasetSource.load` and validation-service's own `dataset_reference` handling,
mirrored verbatim in `dashboard-web`'s `run_new_submit`) is one of three dict shapes today:
`{"path": str}`, `{"inline": dict}`, `{"source": str, start?, end?, field?}` (ADR-0005 stored-dataset
mode, DASH-108). CLAUDE.md: no runtime-validation-behavior change bundled silently.

## Design
Pattern: none new — schema-typing only (implementation-plan.md section 7 doesn't call for a pattern
here).
Files touched (scoped to `libs/common`, mirrored in `gateway-api`'s own copy per its README's
version-sync convention — two tickets' worth of files but one logical change, kept as one ticket since
both edits are mechanical copies of the same typed model):
- `libs/common/src/naive_first_common/contracts.py` — new `DatasetReference` `RootModel`/`Union` of
  three `TypedDict`-equivalent Pydantic models (`PathDatasetReference`, `InlineDatasetReference`,
  `StoredDatasetReference`), each with at least one `Field(examples=[...])`. `RunRequest.dataset_reference`
  retyped from `dict` to this union.
- `services/gateway-api`'s local mirrored `RunRequest` (find via grep — same field) updated identically.
- `services/gateway-api/tests/test_openapi_*.py` (or a new file) — schema assertion.
- `services/gateway-api/README.md`, `libs/common/README.md` — contract-change note.
