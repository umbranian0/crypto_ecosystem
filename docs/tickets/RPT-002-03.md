# RPT-002-03 -- gateway-api proxy accepts optional `kind`/scope fields on `POST /reports/generate`

**Status: done.** Module: `services/gateway-api` only. Depends on RPT-002-02. Story: RPT-002. Sprint: docs/sprints/sprint-65.md.

## Analysis
Gateway's `GenerateReportRequest` (src/app/routers/reports.py) is a field-for-field copy of reporting-service's and today only has `run_id`. It must mirror the new shape: `kind: Literal["validation_audit","consistency_trend"] = "validation_audit"`, `run_id: str | None = None`, `dataset_id: str | None = None`, `horizon: int | None = None`. Backward compatible: a body with only `run_id` forwards the same payload as today.

## Design
- Edit only `routers/reports.py` models/forwarding. A legacy `{run_id}` body must forward exactly `{"run_id": ...}` as before (existing tests assert the forwarded payload; they must stay unmodified and green) -- use `model_dump(exclude_unset=True)` or equivalent that keeps it identical. Combination validation is downstream's job (its 422 passes through `_raise_for_error`); do not duplicate the validator here beyond types. Update the module docstring's "version-sync point".
- Pattern: none. DRY: reuse `_call_downstream`/`_raise_for_error` as is.
