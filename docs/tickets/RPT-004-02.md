# RPT-004-02 -- gateway-api pass-through of `GET /reports/{id}/diff/{other_id}`

**Status: done.** Module: `services/gateway-api` only. Depends on RPT-004-01. Story: RPT-004. Sprint: docs/sprints/sprint-65.md.

## Analysis / Design
Add `GET /reports/{report_id}/diff/{other_id}` to `src/app/routers/reports.py`, authenticated via `get_authenticated_tenant`, forwarding with `build_downstream_headers(tenant)` to reporting-service's same path and returning the JSON body verbatim with the downstream status (4xx/5xx via the existing `_raise_for_error`, so 404 and 422 pass through). Return the downstream JSON as-is (e.g. `JSONResponse(response.json())`) rather than duplicating the diff's response model locally -- note this choice in the docstring (the diff shape is owned by reporting-service). Verify the route does not collide with `GET /reports/{report_id}` (distinct path depth). Reuse `_call_downstream`/`_raise_for_error`.
