# UAT-012 — Skip-to-content link

**Module**: `services/dashboard-web`. **Depends on**: none. Sequenced before UAT-014 (both touch
`base.html`'s nav/header region).

## Analysis
Story: `docs/product/backlog-uat-findings.md` UAT-012. Standard accessibility pattern — visually-hidden-
until-focused link, first focusable element, targeting the main content landmark.

## Design
Pattern: none new. Files touched: `services/dashboard-web/src/app/templates/base.html` only (add the
link as the very first element inside `<body>`, plus an `id="main-content"` or equivalent on the
existing main landmark if not already present, plus a small CSS rule — reuse existing `style.css` if one
exists, extend rather than create a second stylesheet).
**DRY check note**: grep `<main` / `id="main` in `base.html` before editing — reuse the existing main
landmark if present rather than introducing a duplicate wrapper.
