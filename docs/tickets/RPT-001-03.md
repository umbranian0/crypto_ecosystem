Sprint-63 decision 5 (orchestrator confirmed in scope; disclosed addition to the backlog AC). Gateway currently rebuilds JSON, so PDF cannot pass.
## Design
File: `src/app/routers/reports.py` (+ tests, README). Add optional `format` query param to existing `get_report`; when `format` is absent behavior is byte-identical (same code path, same response_model). When given, forward `params={"format": ...}` via `_call_downstream`, `_raise_for_error` on errors (so 404/422 forward), and return `Response(content=bytes, media_type="application/pdf", headers=Content-Disposition from downstream)`. Gateway must not inspect content. Auth via existing `get_authenticated_tenant`. Keep OpenAPI sane (route must still document the JSON default; response_model stays). Check `test_openapi_*` tests still pass. DRY: reuse runs.py helpers as the module already does.
