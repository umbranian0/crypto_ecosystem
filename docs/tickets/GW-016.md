## Design
Pattern: none new beyond DI (GW-006/GW-007's dependencies injected, same as the existing three routes) — pure proxy, no Strategy/Factory. File: `services/gateway-api/src/app/routers/runs.py` (existing file — GW-008 already put `POST /runs`/`GET /runs/{id}`/`GET /runs/{id}/splits` here; this ticket adds a fourth handler, additive, no other ticket in this sprint touches this file). Response/request models: import `RunSummaryResponse` from `naive_first_common.contracts` (added by VS-022) — do not redefine.

Handler flow (fixed, mirrors the existing three exactly): resolve `tenant: TenantContext = Depends(get_authenticated_tenant)` (GW-006) → `headers = build_downstream_headers(tenant)` (GW-007) → forward `limit`/`offset` query params + headers via `_call_downstream(client.get, "/runs", params={...}, headers=headers)` → `_raise_for_error(response)` → parse into a response envelope model and return.

New response envelope model needed: `runs.py` currently has no wrapper model for `{items, limit, offset, total}` — define a small local `RunListResponse` (or equivalent name) in `runs.py` composed of `items: list[RunSummaryResponse]` (imported) + `limit`/`offset`/`total` — this envelope shape itself is `gateway-api`'s own proxy-response Pydantic model (mirroring how the existing three handlers already define their own Pydantic response models even though `RunResponse`/`RunDetailResponse`/`SplitResultResponse` are imported), not a new shared-contract type (the sprint's own scope only requires `RunSummaryResponse` — the item shape — to be canonical; the pagination envelope around it is this proxy's own wire shape, matching `validation-service`'s own envelope field names exactly since it's pass-through, not reimplementation).

DRY check (performed before writing this ticket): grepped `services/gateway-api/src/app/routers/runs.py` — the exact `_call_downstream`/`_raise_for_error`/`build_downstream_headers` helpers already exist and must be reused unmodified, not duplicated; `ValidationServiceClientDep` already exists in `dependencies/http_client.py`, no new client needed.
