# NFE-012 — Harvey correction for overlapping horizons

**Status: done**

## Analysis
Story: NFE-012 (Must), depends on NFE-011. Constraining docs: da-tese-ao-produto.md section 2.3.1 ("com correção de variância de longo prazo para horizontes sobrepostos (Harvey et al. 1997)") and section 2.7's explicit ethical risk ("Evitar reivindicar significância estatística em horizontes sobrepostos sem a correção de variância adequada"). CLAUDE.md repeats this as a cross-cutting rule: "don't skip it in code that computes DM statistics."

## Design
No new pattern. File touched: `dm_test.py` only (extend NFE-011's `dm_test`), `tests/test_dm_test.py` (extend). DRY check: grep `dm_test.py` for the existing DM statistic computation and extend it in place — the correction must be applied *inside* the one `dm_test` code path, not as a second parallel function a caller could choose to skip.

Correction applied automatically whenever `horizon > 1` is inferred/passed — **always applied, never an opt-in flag**. For `horizon == 1` (non-overlapping), corrected ≈ uncorrected (no-op in practice, not merely "flag defaults off").
