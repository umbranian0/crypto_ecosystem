# VS-023 (revised) — `IngestionServiceDatasetSource`: a fourth `DatasetSource` backed by `ingestion-service`

**Sprint**: 18. **Module**: `services/validation-service`. **Status**: todo. **Priority**: Must.
**Depends on**: `INGEST-009` reachable by Compose hostname. **Blocks**: `VS-024` (same file, run after).

## Analysis
Story: backlog `VS-023`, **superseded** by solution-design.md section 8.4/ADR-0005: `reference` shape is
`{"source", "start", "end", "field"}` (continuous-table slice), not `{"dataset_id", "field"}`. Hard rule
(binding, this backlog's own Design decision section): `validation-service` must never read
`ingestion.*` directly — only via `ingestion-service`'s HTTP API, by Compose hostname, same precedent as
`reporting-service` → `validation-service`.

## Design
Pattern: Adapter, implementing the existing `DatasetSource` Protocol. File: `services/validation-service/
src/app/dataset_source.py` (extend, `CompositeDatasetSource` gains a fourth `elif` branch dispatching on
`"source"` key — the three existing branches unchanged). **DRY check**: reuses
`InlineOrLocalFileDatasetSource._build_series` for JSON→`pd.Series` parsing — no second implementation.

## Implementation acceptance criteria
- [ ] `IngestionServiceDatasetSource(httpx_client, base_url)`, `load(reference)` calls `GET
  /datasets/{source}/series?start=&end=&field=` on `ingestion-service` directly by Compose hostname
  (`http://ingestion-service:8000`), never through `gateway-api`.
- [ ] `reference` shape: `{"source": str, "start": str | None, "end": str | None, "field": str | None}`.
- [ ] `CompositeDatasetSource` dispatches on `"source"` (distinct from `"inline"`/`"path"`/
  `"object_key"`) — existing three branches' tests pass unmodified.
- [ ] Downstream failure (timeout, 404, malformed response) raises `DatasetSourceError`, same as every
  other source.
- [ ] Hard rule proof: `grep -R "ingestion\." services/validation-service/src` returns nothing beyond
  comments.

## Test acceptance criteria
- [ ] Successful load, downstream 404, downstream timeout — fake `httpx` transport, never a real
  `ingestion-service` call.
- [ ] Existing `tests/test_dataset_source.py` suite passes unmodified.
