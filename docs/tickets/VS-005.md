## Design
Pattern: **Adapter** (implementation-plan.md section 7 — same style as `ingestion-service`'s future connectors, one interface, swappable implementations). Files: `src/app/dataset_source.py` (new — `DatasetSource` interface, `InlineOrLocalFileDatasetSource` interim implementation). DRY check: grep `src/app/` for any existing series-loading code (none expected, independent branch).

`DatasetSource.load(reference) -> pd.Series`: `reference` is whatever shape `POST /runs` (VS-006) passes through — for the interim implementation, a dict with either an `"inline"` key (list of `[timestamp, value]` pairs, or `{"timestamps": [...], "values": [...]}`) or a `"path"` key (local filesystem path to a two-column CSV: timestamp, value). Returns a `pd.Series` with a sorted `pd.DatetimeIndex`, in the shape `run_validation_protocol` expects (matches how `tests/test_regression_1h.py` in `naive_first_engine` constructs its `series` argument — a plain `pd.Series` indexed by `DatetimeIndex`).

Malformed input (missing both `inline`/`path`, non-numeric values, unparseable timestamps, empty series) raises a clear `DatasetSourceError(ValueError)` — never returns a silently-empty `pd.Series`, per AC4.
