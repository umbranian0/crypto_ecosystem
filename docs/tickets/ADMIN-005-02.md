# ADMIN-005-02 -- gateway-api `/me/api-keys` router

**Status: todo.** Module: `services/gateway-api` only. Depends on ADMIN-005-01. Sprint doc: docs/sprints/sprint-64.md (Q2, Q4, Q6-Q10).

## Analysis
Tenant-facing list/mint/revoke. Tenant id comes only from the authenticating key; never from path/body.

## Design
- New `app/routers/me_api_keys.py`, mounted in `main.py` (like setup/tenants routers; no downstream proxy). All routes depend on `get_authenticated_key` (from -01).
- `GET /me/api-keys` -> `{items: [{id, created_at, revoked_at, current}]}`; `current` true for the authenticating key. Never `key_hash`/raw key. Include revoked keys.
- `POST /me/api-keys` -> 201 `{id, created_at, api_key}` (raw key once) via `mint_api_key`; response header `Cache-Control: no-store`. Audit row `api_key.self_create`.
- `POST /me/api-keys/{key_id}/revoke`: resolve via `list_api_keys(caller_tenant)` + id match -> generic 404 `"not found"` otherwise; if `key_id` == authenticating key id -> 409 (detail "cannot revoke the key authenticating this request"); then guarded revoke: `last_active` -> 409 (distinct detail); `already_revoked` -> 200 no-op; `revoked` -> 200; `not_found` from the repo -> 404. Response `{key_id, revoked_at}`. Audit `api_key.self_revoke` on every 200 (incl. no-op), none on 404/409. Audit: `audit_log_repository.record(action, caller_tenant_id, correlation_id_var.get())`; no key id/hash/secret in the row.
- DRY: reuse `ApiKeySummary` from `routers/tenants.py` only if cleanly importable; otherwise one small model here (add `current`), say which in a comment. Reuse existing audit repo dep.
- One-line note in README where ADMIN-002 says "operator action" only, if that would now be false.

## Test AC
New `tests/test_me_api_keys.py`: mint (201, raw key authenticates a following request, no-store header, raw key not in later list); list never exposes hash/raw and marks `current`; revoke other key succeeds and the revoked key gets 401 next request; revoke own key 409; revoke last active key 409; already-revoked 200 no-op; cross-tenant: other tenant's key absent from list, revoke 404 and key unchanged; audit rows on 201/200 only (not 404/409) without secrets; no/invalid auth 401; operator token does not satisfy. Full gateway-api suite green.
