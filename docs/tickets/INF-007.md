Status: **done**
Backlog: docs/product/backlog-infra.md, INF-007 [Must]
Sprint: docs/sprints/sprint-06.md, Phase 3
Depends on: INF-001 through INF-006

## Analysis

`infra/README.md` has read "planned" since before this sprint. This ticket is the rollup that
documents the actually-finished state (containers wired, migrations verified) — it cannot be
written accurately until INF-001–006 are done, per the backlog's own dependency.

## Design

- `infra/README.md` status line no longer reads "planned" — states what's actually running
  (`postgres`/`timescaledb`, `redis`, `validation-service`, `gateway-api`), links to
  `docs/product/backlog-infra.md`, and states plainly this was built as an explicit debt-sprint
  decision after trigger #4 didn't fire on schedule alongside trigger #3 (mirrors the wording
  pattern validation-service's/gateway-api's own READMEs already use for their interim-SQLite
  disclosures).
- `.env.example` at repo root or `infra/` lists every variable INF-001–004 introduced
  (`DATABASE_URL` shape — single Postgres instance, two schemas; `REDIS_URL`), with comments
  distinguishing Compose-network values (`postgres:5432`, `redis:6379`) from local
  non-Compose-dev values (`localhost:5432`, `localhost:6379`) — same distinction gateway-api's
  README already draws for `VALIDATION_SERVICE_URL`.
- States explicitly that `ingestion-service`, `reporting-service`, `dashboard-web` are still not
  wired into compose, naming their triggers (#6, #7, #8) as the reason.
