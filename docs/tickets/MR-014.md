**MR-013 — verified results** (Tech Lead's own re-run, `cd research && ./.venv/Scripts/python.exe -m
pytest tests/test_stacking_ensemble.py -v -s`): 7 passed. The leakage-guard unit test
(`test_meta_learner_fits_on_holdout_out_of_sample_predictions_not_in_sample`) was read in full by the Tech
Lead and genuinely exercises the in-sample-vs-holdout distinction: it monkeypatches both base models with a
`_FakeMemorizingBaseModel` that returns exact true values for rows it was "trained" on and a constant `0.0`
for genuinely unseen rows, and a `_SpyRidge` that records the exact `X`/`y` its `.fit()` receives. It then
asserts the meta-learner's `y` has the holdout portion's length/index (not the base-fit portion's), and
that its `X` is all-zero (the fake's out-of-sample constant), never the memorized in-sample values — a
naively-in-sample-fit implementation would produce a longer `y` with the wrong index and features
bit-identical to the target, which each assertion would independently catch. `stacking_ensemble.py` itself
was traced directly by the Tech Lead: the chronological 80/20 split (`_split_train_chronologically`,
position-based, never shuffled) is used; the meta-learner's `Ridge().fit()` call receives only
`meta_features`/`meta_target` built from `base_fit_portion`-trained models' predictions on
`meta_fit_holdout_portion` (genuinely out-of-sample); fresh `LightGBMBaseline()`/`RegimeHMMBaseline()`
instances are constructed both for the holdout step and the final full-train refit step; no instance state
is stored on `self`. Meta-learner: `sklearn.linear_model.Ridge`. Zero new `research/pyproject.toml`
dependency confirmed (`git diff research/pyproject.toml` empty).

Real-data run (MR-012's already-landed widened window, same tenant/source/date-range, reused verbatim, no
second fetch): 17,496 returns, 68 splits per horizon. DM-vs-Naive0 verdict counts:
- 1h (`purge_gap=6`): `{'better': 0, 'worse': 5, 'no significant difference': 63}`
- 6h (`purge_gap=6`): `{'better': 2, 'worse': 6, 'no significant difference': 60}`
- 24h (`purge_gap=24`): `{'better': 0, 'worse': 1, 'no significant difference': 67}`

The stacking ensemble does not beat Naive0 in a stable, significant way at any horizon either — a fourth
independent real-data confirmation of the thesis's core finding, not a failed story.
