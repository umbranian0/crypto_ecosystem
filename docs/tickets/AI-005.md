## Sprint 50 slice — `services/dashboard-web/README.md` (AI-003)

New "AI-assisted features (AI-003)" section, same per-ticket format as the reporting-service section
below, stating:
- What it does: an optional natural-language Q&A assistant (`GET /assistant`, `POST /assistant/ask`)
  answering a tenant's question about their own stored validation-run history, retrieved via
  `gateway-api`'s existing `GET /runs`/`GET /runs/{id}`/`GET /runs/{id}/splits` (a fixed, bounded 0-3-call
  pattern per question, `DownstreamHeadersDep`-scoped to the caller's own tenant — never a direct DB
  read, never an open-ended retrieval loop).
- What it does not do, stated plainly: never predicts prices/markets (out-of-scope questions are refused
  with a fixed message before any model call ever happens), never surfaces another tenant's data (proven
  by a real cross-tenant-leak-guard test, VS-024 precedent), never ships an answer without a citation to
  the real run id(s)/split(s) it drew from (citation is appended deterministically from the actual
  retrieved data, not trusted to the model's own text), and degrades to a fixed "assistant unavailable"
  message on any model-call failure/timeout — never a crash, never a hang.
- Where the model actually runs: hosted open-weights inference API over HTTPS (ADR-0011), same endpoint
  `reporting-service`'s AI-002 narrative feature already calls — no local model, no new container, no
  second credential.
- The `AssistClient` Adapter seam now lives in `libs/ai_assist` (`naive_first_ai_assist.client`), shared
  with `reporting-service`'s narrative client (AI-003-REFACTOR, this sprint's second-duplication
  extraction) — both services import the same package rather than each hand-rolling a hosted-API client;
  tests use a fake implementation, never live network access.
- Where the banned-term/out-of-scope-refusal/cross-tenant-leak/citation/degradation tests live (exact
  file paths from AI-003's actual diff).
- Env vars: `NARRATIVE_API_URL`/`NARRATIVE_API_KEY`/`NARRATIVE_API_TIMEOUT_SECONDS`, reused unchanged
  (not a new var set) via `libs/ai_assist`'s defaults — pointer to `infra/README.md`'s disclosure section.
