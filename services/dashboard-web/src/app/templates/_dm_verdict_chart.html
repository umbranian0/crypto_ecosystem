{# RAV-003: DM-test verdict-by-split chart, server-rendered inline SVG per ADR-0006 (docs/adr/0006-dashboard-web-charting-server-rendered-svg.md) -- no client-side charting library, no Python plotting library. `dm_verdict_chart` is `app/charting.py`'s `build_dm_verdict_chart(splits)` output, computed by `run_detail`'s handler (charting.py has no Jinja2 import; this partial is the only place its geometry becomes markup). Each split's `dm_verdict` field is shown verbatim -- no recomputation of the verdict here, the Harvey et al. (1997)-corrected DM test already ran upstream in `naive_first_engine`/`validation-service`. "Better"/"worse" describe this split's own out-of-sample error relative to Naive0 under that test, never "the model recommends" or "predicts." A split whose `dm_statistic`/ `dm_pvalue` are both null (a single-test-point split's genuinely undefined DM statistic) is its own distinct "undefined for this split" category, never dropped or folded into "no significant difference." Colors are four named CSS variables only (`.verdict-bar-better`, `.verdict-bar-worse`, `.verdict-bar-no-sig-diff`, `.verdict-bar-undefined` -- style.css), chosen to be status-neutral and never a green="better"/red="worse" pairing. #}

DM-test verdict by split (vs. Naive0)

"Better"/"worse" describe this split's own out-of-sample error relative to the Naive0 baseline, under the Harvey-corrected Diebold-Mariano test already applied upstream. A split whose DM statistic is undefined (a single-test-point split has zero variance to test) is shown separately, not merged into "no significant difference."
